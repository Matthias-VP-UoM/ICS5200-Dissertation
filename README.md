# ICS5200-Dissertation
This repository contains the codebase for my MSc in Artificial Intelligence Dissertation at the University of Malta, which falls under study unit ***ICS5200***.

## Repository Structre

### Folders
- **data** - This folder contains the core data responsible for running the entire implementation, including the DOM and image features extracted from each webpage in the dataset, along with the annotations from the data.
- **dataset_final** - This folder contains the final, preprocessed webpage screenshot which are generated from the **dataset_raw** folder. These are generated by running the **image_processing.py** script at the root of the project repository.
- **dataset_raw** - This folder contains the raw webpage screenshots, which are then later preprocessed and stored in the **dataset_final** folder mentioned above.
- **models** - The folder which contains the code for building all the baseline models implemented in this project
- **outputs** - This folder stores the output which is generated using this framework, including plots, models, results, and xAI visualisations.
- **src** - This contains the scripts for extracting the DOM/HTML contents from the retrieved webpages and extracting all the necessary DOM and image features.
- **streamlit_app** - This folder contains the Streamlit application, which was developed to provide users with the ability to assess custom webpage screenshots and receive feedback based on their accessibility level.
- **utils** - The utility scripts folder used to supplement the main scripts used in the project

NOTE: Due to size constraints, only the content of the **dataset_final**, **dataset_raw** and **output/models** folders cannot be viewed in this repository. Instead, these would need to be accessed via Google Drive. More information on this is provided below.

### Files
- **dataset_processor.py** - Copies all images from the **dataset_raw** folder and places them in the **dataset_final** folder, maintaining their original location in the hierarchy.
- **feature_combiner.ipynb** - Combines all the extracted DOM and images features into a single file which contains the unannotated dataset. NOTE: This should be run after extracting all DOM and image features from the webpages.
- **image_processing.py** - Performs image preprocessing of all webpage screenshots located in the **dataset_final** folder.
- **manifest.csv** - Stores the general information of each webpage screenshot, including page type, screenshot path, HTML path and original URL.
- **manifest_processor.py** - Builds the **manifest.csv** file.
- **plot_results.ipynb** - Plots visual representations of the results generated from the baseline model evaluation.
- **preprocessing.py** - Preprocesses the **final_dataset.csv** file located in the **data** directory and annotates them with the accessibility heuristic features extracted.
- **train_baselines.py** - Main pipeline for training and evaluating the classical machine learning models (i.e. Gradient Boosting and Random Forests).
- **train_dl_baselines.ipynb** - Main pipeline for training and evaluating the deep learning models (i.e. ResNet-18, ResNet-50, VGG-16, ViT-B/16, and Swin-T). **NOTE: This entire notebook was run using Google Colab. Further information regarding its usage is highlighted below.**
- **train_hybrid_models.ipynb** - Main pipeline for training and evaluating the hybrid featured-fused models, combining the use of both the baseline classical ML and deep learning models. **NOTE: This entire notebook was run using Google Colab. Further information regarding its usage is highlighted below.**
- **visualise_pred.py** - Generates and stores the SHAP and Grad-CAM visualisations for each prediction in the test set.
- **visualise_pred_overall.ipynb** - Generates and stores the overall SHAP visualisations, aggregating all predictions made within the test set.

## Getting Started with the Application

### Prerequisities
- Python 3.10+

### 1. Clone the repository
The first step is to clone the entire repository, ensuring you have the available code and resources to start the program:

```bash
git clone https://github.com/Matthias-VP-UoM/ICS5200-Dissertation.git
```

### 2. Install package dependencies
In order to use the program, the correct dependencies must be installed. These can be installed using the provided requirements.txt file, which can be done using the below command:

```bash
pip install -r requirements.txt
```

**Important: Kindly note that although the versions of the libraries indicated in the requirements.txt file will work fine with the code provided, the use of Google Colab may result in these libraries utilising a more recent version. Additional details on the use of Colab in this project is provided below.**

### 3. Gather the necessary data and files
Due to file size constraints, the repository does not include the full dataset or the models that were trained using the training scripts provided.

Instead, these can be accessed by using the following Google link:
https://drive.google.com/drive/folders/1dgEqFXd9tdGMVD-4JgXmYyqXCsUZj4Ah?usp=sharing

To use the files contained in the link, first download and then upload them to the following directories:
- The **"models"** folder should be placed inside the "outputs" directory in the root of the project working directory.
- The **"dataset_final"** and **"dataset_raw"** folders should be placed in the root of the project working directory.

**Note: If it asks you to replace any files, kindly refrain from doing so, as this will only allow you to place the missing files which are not available in this repository.**

## Note Regarding the Use of Google Colab

Throughout the development of this pipeline, only the **train_dl_baselines** and **train_hybrid_models** Jupyter notebooks were run using Google Colab due to the need to train, store and use high resource models (mainly the deep learning and hybrid models implemented in this project), which could not be run on the computational resources that were available on the machine used.

While the rest of the Python notebooks can be run normally without necessarily needing to use Google Colab, kindly feel free to use the software for these notebooks if you prefer.
